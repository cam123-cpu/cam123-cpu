🧾 <a href="https://github.com/cam123-cpu/Invoice-Anomaly-Detector">Invoice Anomaly Detector</a>

Flags suspicious invoices for human review. Twelve signals (eleven audit rules plus an Isolation Forest) feed a risk-ranked queue, and reviewer decisions tune scoring per company.

Duplicates, bank-detail changes, split invoices, look-alike vendors
Upload Excel/CSV/PDF → get back a ranked queue & payment file
Multi-company deployment, each sees only its own data

🛡️ <a href="https://github.com/cam123-cpu/agent-checkpoint">Agent Checkpoint</a>

An independent checkpoint between AI agents and a company's money. Before an agent pays, refunds or edits a supplier's bank details, it must show what, why and who asked.

Returns go / pause / block in about a millisecond
Money moves only with a signed, single-use receipt (Ed25519)
Tamper-evident audit log; works with any agent over MCP or HTTP

🛩️ <a href="https://github.com/cam123-cpu/Airspace-Control">Airspace Control</a>

Counter-drone detection for prisons and other soft targets. Radar, RF, acoustic and camera sensors, each unreliable on its own, are simulated from published specs and fused into a single track.

Where the drone is, where the package will land, where the pilot is standing
3D browser simulator, synthetic training data, multi-tenant operator platform

🏥 <a href="https://github.com/cam123-cpu/discharge-check">Discharge Check</a>

Checks hospital discharge records against CMS rules before the physician signs. Ingests discharge notes or FHIR R4 data, writes a brief for each patient, and flags every gap with the exact line and a suggested fix.

20 rules from 42 CFR 482.24 and 482.43, checked before signing
Every model "pass" must carry a verbatim quote verified in the record
Compliance dashboard by rule, doctor and unit; synthetic data only
